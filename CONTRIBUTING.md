# Contributing

1. Open an issue before large changes.
2. Keep changes focused and document Windows/macOS differences.
3. Use synthetic media for tests; never commit real user videos, screenshots,
   logs, credentials or model weights.
4. Run `python -m pytest -q -m "not integration"` before opening a pull request.
5. Include licensing and provenance information for any third-party code or
   asset.

By contributing, you agree that your contribution may be distributed under
the project license selected for the release.
