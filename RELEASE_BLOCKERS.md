# Public release blockers

This checklist records the conditions for future releases and is kept in the
repository for maintainers.

Before the first public push:

1. Confirm each contributor has the right to publish their contribution under
   Apache-2.0.
2. Preserve the Apache-2.0 notices for the upstream Video Subtitle Remover
   code and FSRCNN asset.
3. Keep ProPainter and any other non-commercial model/runtime outside the
   public base repository unless explicit redistribution permission is obtained.
4. Re-run the secret, path, media, binary and large-file scans immediately
   before staging and pushing.
